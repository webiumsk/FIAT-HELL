Flash firmware na ESP32-S3

Pripoj ESP32-8048S050 cez USB. Ak treba manuálny boot: drž BOOT, stlač RESET, pusť a klikni Flash.

Tento prehliadač nepodporuje Web Serial. Použi Chrome alebo Edge na desktope (verzia 89+).
Web Serial vyžaduje HTTPS. Otvor stránku cez https:// (nie http://).

Postup flashovania:

  1. Pripoj ESP32-8048S050 cez USB kábel
  2. Manuálny boot do flash módu: drž BOOT, stlač a pusť RESET, potom pusť BOOT
  3. Klikni na tlačidlo ⚡ Flash FIAT HELL ATM
  4. Vyber správny COM port (napr. COM3 na Windows, /dev/ttyUSB0 na Linux)
  5. Počkaj na dokončenie (~2 min)
  6. Po flashovaní stlač RESET
ℹ️ Windows driver: Ak port nevidíš, nainštaluj CH340 driver.

Po prvom spustení:

  1. Zariadenie spustí WiFi AP "LN ATM-xxxx"
  2. Pripoj sa k tejto sieti (heslo: changeme alebo vlastné)
  3. Prehliadač automaticky otvorí konfiguračný portál (captive portal)
  4. Alebo manuálne otvor http://192.168.4.1
  5. Nastav WiFi, LNbits/Blink API kľúče, meny a bankovky
