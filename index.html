⚡ FIAT HELL

Bitcoin Lightning ATM — Web Flasher & Konfigurátor

Vyžaduje Chrome alebo Edge na desktope (Web Serial API)

🔒 Statická stránka — tvoje údaje neopúšťajú prehliadač (idú len cez USB do zariadenia). Zo siete sa načíta iba zoznam verzií z GitHubu a pri výbere staršej verzie aj jej .bin súbory. Detaily v Návode.

ℹ️ Vyplň konfiguráciu nižšie a potom vo Flash kroku klikni na ⚡ Flash + nahraj konfig — firmware aj nastavenia sa nahrajú automaticky cez USB. Konfiguráciu môžeš zmeniť aj neskôr cez WiFi AP portál zariadenia.
Nahratá cez USB — netreba portál. Sken sietí funguje, keď je v zariadení FIAT-HELL firmvér (pri prvom flashi zadaj názov ručne).
Heslo pre "LN ATM-xxxx" AP aj pre webový portál (meno: admin)
Voliteľné — heslá aj Flash/Blink API kľúč sa uložia do localStorage tohto prehliadača, aby si ich nemusel zadávať pri každom použití. Bez zaškrtnutia sa tajné hodnoty nepamätajú. Nepoužívaj na cudzom počítači.
Prázdne = žiadny. Špeciálne: DVADSATJEDEN, AMITY
Blink / Flash vyžadujú internet (Flash = náhrada Blinku pre EÚ). LNbits funguje aj offline.
CoinYEP – odporúčané. ExchangeApi – pre exotické meny (HNL, …).
Napr. EUR, USD, CZK, HNL …

Ako nahrať konfiguráciu?

  1. Automaticky (odporúčané): Prejdi na Flash krok a klikni ⚡ Flash + nahraj konfig — firmware aj nastavenia sa nahrajú naraz.
  2. Manuálne (záloha): Stiahni ZIP, po flashovaní sa pripoj na AP "LN ATM-xxxx", otvor http://192.168.4.1 a zadaj hodnoty z JSON súborov.
⚠ Vyžaduje Chrome alebo Edge na desktope. iOS a Firefox nie sú podporované.

Flash firmware

Pripoj zariadenie cez USB. Manuálny boot: drž BOOT, stlač RESET, pusť a klikni Flash.

Nevieš, ktorú máš? Pozri nápis na zadnej strane dosky:
• ESP32-8048S050 — veľký 5-palcový displej (800×480), nápis „ESP32-8048S050" / „Sunton"
• WT32-SC01 — menší 3,5-palcový displej (480×320), nápis „WT32-SC01"
Každá doska má vlastný firmware a iné flash adresy — zlý výber = zariadenie nenabootuje (oprava: flashni znova so správnou doskou).
Po výbere staršej verzie sa .bin súbory stiahnu z GitHub releases.

    


    

      
Postup:

      
    
        
  1. Vyplň konfiguráciu v Kroku 1 (alebo preskočiť — nastav neskôr cez portál)
    2. 
        
  2. Vyber dosku (S3 / WT32) a pripoj ju cez USB kábel
    3. 
        
  3. Manuálny boot: drž BOOT, stlač a pusť RESET, potom pusť BOOT
    4.

    6.

1️⃣ Získaj Flash API kľúč (robí sa priamo v ATM)

      
    
        
  1. Nainštaluj si appku Flash (Android / iOS) a zaregistruj sa svojím telefónnym číslom.
    2. 
        
  2. V appke prejdi do Cash walletu a vlož si doň prostriedky na výplaty (ATM vypláca z Cash walletu — Bitcoin wallet v appke je non-custodiálny a ATM ho použiť nevie).
    3. 
        
  3. Naflashuj ATM (kroky 2–3 nižšie), pripoj ho na WiFi a otvor v prehliadači stránku zariadenia /flashkey (odkaz je aj v portáli pri poli API kľúč).
    4. 
        
  4. Postupuj podľa sprievodcu: v appke si vyžiadaš SMS kód, ale zadáš ho do sprievodcu (nie do appky). Kľúč sa vytvorí a uloží priamo do zariadenia — nikam inam sa neposiela. Zobrazí sa len raz, odlož si ho.
    5. 
      

    


    

      
2️⃣ Konfigurácia (Krok 1)

      
    
        
  1. Už nakonfigurované ATM? Klikni ⬇ Načítať zo zariadenia — formulár sa naplní aktuálnymi hodnotami. Kľúče a heslá zariadenie nikdy neposiela: príslušné polia ukážu „uložené v zariadení" a pri nahratí sa nezmenia, pokiaľ ich neprepíšeš.
    2. 
        
  2. Vyplň menu, hodnoty bankoviek, poplatok a heslo AP portálu (min. 8 znakov).
    3. 
        
  3. WiFi: ak už je v zariadení FIAT-HELL firmvér, klikni 📶 Načítať siete zo zariadenia a vyber sieť zo zoznamu; pri úplne prvom flashi zadaj názov ručne.
    4. 
        
  4. Heslá: štandardne sa nepamätajú. Zaškrtni „Zapamätať aj heslá", ak chceš, aby ostali v tomto prehliadači, alebo použi 💾 Uložiť profil — celý formulár (vrátane hesiel) sa uloží do súboru, ktorý si držíš sám a kedykoľvek načítaš aj na inom počítači.
    5. 
        
  5. Funding source Flash: API kľúč vyplň, ak ho už máš zo sprievodcu; Wallet ID si zariadenie zistí samo.
    6. 
      

    


    

      
3️⃣ Flash (Krok 2)

      
    
        
  1. Vyber dosku — každá má vlastný firmware a iné flash adresy. Model zistíš z nápisu na zadnej strane dosky: „ESP32-8048S050" = veľký 5" displej, „WT32-SC01" = menší 3,5" displej.
    2. 
        
  2. ESP32-8048S050 (S3): pred flashom drž BOOT, stlač a pusť RESET, potom pusť BOOT. WT32-SC01: resetne sa sám.
    3. 
        
  3. Klikni ⚡ Flash + nahraj konfig a vyber COM port. Firmware aj konfigurácia sa nahrajú naraz (~2 min).
    4. 
        
  4. Pri už naflashovanom zariadení stačí ⬆ Iba konfig — bez flashovania.
    5. 
      

    


    

      
4️⃣ Prvé spustenie

      
    
        
  1. Zariadenie sa reštartuje, pripojí na WiFi a hlavná obrazovka ukáže kurz a zostatok tvojho Cash walletu. Ak ukazuje OFFLINE, skontroluj WiFi; ak 0, skontroluj Cash zostatok a API kľúč.
    2. 
        
  2. Nastavenia zmeníš cez AP portál: podrž BOOT pri štarte (S3) alebo klikni na logo, pripoj sa na AP LN ATM-xxxx a otvor http://192.168.4.1 (meno admin + tvoje heslo portálu).
    3. 
        
  3. Skúšobná výplata: vlož najmenšiu bankovku a vyplať si ju do vlastnej peňaženky.
    4. 
      

    


    

      
🔒 Súkromie a riešenie problémov

      
    
        
  1. Súkromie: táto stránka je statická (GitHub Pages) — všetko sa deje v tvojom prehliadači a cez USB kábel. Zo siete sa načíta iba zoznam verzií z GitHub API a pri výbere staršej verzie firmvéru aj jej .bin súbory z GitHub releasov (lokálna verzia sa nesťahuje). Flash API kľúč vzniká priamo v zariadení a neprechádza cez túto stránku. Zdrojový kód je verejný; v releasoch je aj offline balík flashera.
    2. 
        
  2. Port sa nedá otvoriť / synchronizácia zlyhá: port smie používať len jeden program — zavri sériový monitor (PlatformIO/Arduino) a ostatné taby flashera.
    3. 
        
  3. Výplata zlyhá (PAYMENT FAILED): skontroluj zostatok Cash walletu (musí pokryť sumu + poplatok) a platnosť API kľúča.
    4. 
        
  4. Strata/únik API kľúča: v appke sa nedá spravovať — kľúč zrušíš vytvorením nového cez sprievodcu /flashkey (starý zneplatni cez apiKeyRevoke, návod v repozitári docs/OPERATOR.md).
    5.
